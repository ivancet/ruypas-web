进口一辆车要多少钱？

这取决于车辆和卖家，所以价格面议，每辆车我们都会提供书面明细。最终价格包括：

  1. 车辆在原产国的价格
  2. 运输到西班牙
  3. 注册税（IEDMT）：电动车 CO₂ 排放为 0 g/km，税率为 0 %
  4. 增值税：根据卖家是车商还是个人、车辆是新车还是二手车，在原产国或在西班牙缴纳
  5. ITV、DGT 和牌照费用，以及市政车辆税
  6. 我们的服务费

请向我们索取某辆具体车辆或您想要的车型的费用明细。

进口常见问题

你们从哪些国家进口？

主要是荷兰和德国，那里二手电动车选择很多。其他欧盟国家可咨询。

只做特斯拉吗？

不是。我们专注于特斯拉和其他电动车，也可以帮您找所需的车。

需要多长时间？

取决于车辆、运输以及 ITV 和 DGT 的预约。我们会针对每种情况给出估计；在途车辆会显示预计到达时间。

怎么知道电池状况好不好？

如果有电池健康（SOH）报告或可以检测，我们都会索取。没有报告时，车辆页面会明确注明。

可以用公司名义购买吗？

可以。公司和个体户的发票与增值税处理方式不同，开始前我们会解释清楚。

为什么不显示价格？

因为最终价格包含运输、手续和税费，视具体情况而定。联系我们，我们会发送您感兴趣车辆的价格和明细。
